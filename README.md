# AurPadho

How many books will you read this year? **Bas 10 minute aur.**

A one-page, no-backend website: everything is in `index.html` (only Google Fonts load from outside).

- **Live:** https://aurpadho.com
- **Link previews:** `og-image.png` must stay next to `index.html`.
- **Each October:** update the year in the `<title>`, `description` and `og:title` tags (WhatsApp and Instagram read those without running the page's code). The page itself switches the year automatically.
- **Speed-test passages:** edit the `PASSAGES` array in section 4 of the script.
